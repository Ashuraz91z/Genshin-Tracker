# Code de conduite

Soyez respectueux : on critique le code, pas les personnes. Pas d'insultes, de harcèlement ni de publication des informations privées d'autrui (UID, adresses e-mail, captures de comptes). Les messages qui ne respectent pas ces règles peuvent être supprimés et leurs auteurs bloqués par les mainteneurs.

Pour signaler un comportement, écrivez à contact@genshin-tracker.com.
